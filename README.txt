## Add your photo
Copy your portrait image from:
C:\Users\Mohan Ashok Jaykar\Downloads\Mohan_Profile_Photo.jpeg

Paste it into `assets/images/` and keep the filename exactly:
`Mohan_Profile_Photo.jpeg`

If the photo has a different extension, update the `src` value in `index.html`.

## Run
Open `index.html` in your browser, or use VS Code Live Server.

## Customize
- Change the email address in the `mailto:` link in `index.html`.
- Update the About Me paragraph if you want different text.
- LinkedIn and GitHub links are already added.
- The page uses only HTML and CSS; no JavaScript.
